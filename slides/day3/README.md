## Day 3 learning arc

You make the Day 2 docs assistant production-shaped: preserve owned conversation state, stream typed updates, return a typed triage result, add robust middleware, connect MCP tools, apply read-first Azure DevOps controls, and evaluate tool use (Module 7). Module 9 frames a proposed future lab; this change intentionally adds no `labs/day3/` implementation.
